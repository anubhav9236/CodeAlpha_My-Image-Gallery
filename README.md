#  My Image Gallery

A responsive and interactive **Image Gallery** built using **HTML, CSS, and JavaScript** as part of the **CodeAlpha Frontend Development Internship**.

The project allows users to browse images, filter them by category, and view images in an interactive lightbox with next/previous navigation.

---

## ✨ Features

* 📸 Responsive image gallery
* 🔍 Lightbox image viewer
* ⬅️ Previous image navigation
* ➡️ Next image navigation
* ⌨️ Keyboard navigation using Arrow Keys
* ❌ Close lightbox button
* 🖱️ Image hover effects
* ✨ Smooth transitions and animations
* 📱 Fully responsive design
* 🏷️ Image categories/filters
* 🔢 Image counter
* 🌙 Dark lightbox background
* ⚡ Lazy loading for images
* 📱 Mobile, tablet, and desktop support

---

## 🗂️ Image Categories

The gallery contains images from different categories:

* 🌿 Nature
* 🐶 Animals
* ✈️ Travel

Users can select **All**, **Nature**, **Animals**, or **Travel** to filter the displayed images.

## 🛠️ Technologies Used

* **HTML5** — Structure of the website
* **CSS3** — Styling, responsive layout, animations, and hover effects
* **JavaScript** — Gallery filtering, lightbox, navigation, and keyboard controls

## 🎯 How the Gallery Works

### Image Gallery

Images are displayed in a responsive grid layout.

### Image Hover

When the user moves the mouse over an image:

* The image smoothly zooms in.
* The image becomes slightly darker.
* The image title and category appear.

### Lightbox

Clicking an image opens it in a large **lightbox viewer**.

The lightbox provides:

* Previous button
* Next button
* Close button
* Image title
* Image category
* Image counter

### Keyboard Controls

The gallery also supports keyboard navigation:

| Key   | Action         |
| ----- | -------------- |
| `←`   | Previous image |
| `→`   | Next image     |
| `Esc` | Close lightbox |
